# DA-CVA
Official PyTorch implementation of DA-CVA, a distribution-aware complementary representation learning framework for few-shot medical image classification.

## Datasets
The publicly available datasets used in this study can be accessed through their original sources:

- **Chest CT:** [Chest CT-Scan Images — Kaggle](https://www.kaggle.com/datasets/mohamedhanyyy/chest-ctscan-images)
- **HAM10000:** [HAM10000 — Harvard Dataverse](https://doi.org/10.7910/DVN/DBW86T)
